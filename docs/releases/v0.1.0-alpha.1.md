# Engelsiz v0.1.0-alpha.1

First public Linux x86_64 prerelease. Windows distribution and full v0.1 acceptance remain in progress.

## Included

- Localhost application with an embedded React interface and bundled, source-built Kiwix 3.8.2 runtime.
- Turkish Wikipedia Mini/Nopic/Maxi discovery, resumable downloads, checksum verification and atomic installation.
- Offline search/article reading and explicit safe updates that preserve the previous working version on failure.
- Bounded private diagnostics, local font files, and the archive-terminal interface.
- Original runtime sources, patches, build instructions, third-party notices and application attribution under LICENSES.

## Install

Download `engelsiz-linux-x64.tar.gz` and its `.sha256` file, verify with `sha256sum -c engelsiz-linux-x64.tar.gz.sha256`, extract, then run `./engelsiz/engelsiz`.

Linux x86_64, kernel 4.4+ and a desktop browser/opener are the supported baseline. Go, Node, SQLite CLI and a separate Kiwix installation are not required. The package is large because it contains the corresponding-source material. Application data uses the user's XDG directories and is preserved when the extracted program directory is removed.

## Validation

The release preparation passed nine frontend tests, TypeScript/Vite production build, all Go race tests, twelve packaging/notice tests, actionlint and strict validation of all twelve OpenSpec changes. The runtime was source-built in a pinned Ubuntu 22.04 container, checked for generic x64/static ELF properties, and its final link/strip was reproduced byte-for-byte. Existing real-ZIM update success, rollback and offline restart evidence is recorded in the change verification reports.

The user confirmed the Linux candidate runs successfully on their desktop. Isolated empty-rootfs tests additionally covered offline serving/search/reading without developer tools or external shared libraries. A separately recorded clean desktop acceptance matrix remains open; this release does not claim full stable v0.1 readiness.

## Known limits

- No Windows installer is published. Complete Windows runtime DLL/source/redistribution material and clean Windows execution are still pending (#10).
- Full clean-platform acceptance and default CI packaging with configured source bundles remain tracked in #11 and #12.
- Large ZIM downloads require an explicit action and enough free disk space. The Wikipedia data itself is not included.
- This is an alpha; keep existing content and report problems through GitHub issues.
