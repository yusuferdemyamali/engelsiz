# Engelsiz 1.0.0

**Kararlı sürüm.** Wikipedia, haritalar, çeviri, eğitim ve tamamen yerel AI asistanı tek uygulamada. Windows x86_64 ve Linux x86_64 dağıtımları; hesap veya bulut inference gerekmez.

## Yenilikler

- **Yerel AI Asistanı:** Qwen3 Lite (0.6B), Balanced (1.7B) ve Quality (4B) Q4_K_M GGUF profilleri. Motor ve yalnızca seçilen model açık kullanıcı eylemiyle indirilir; SHA-256 ile doğrulanır.
- **Kaynaklı offline yanıtlar:** kurulu Kiwix ZIM ve desteklenen HTML metinlerinde sınırlı retrieval; gerçek, tıklanabilir yerel kaynaklar ve ayrı alıntılar. Kaynak yoksa açık yetersiz bilgi yanıtı, sahte referans yok.
- **Streaming ve durdurma:** Türkçe yanıt akışı, bellek içi sohbet görünümü, model değiştirme/kaldırma ve donanım hedefi uyarıları. CPU varsayılan; motor yalnızca gerektiğinde çalışır ve yanıt sonrası kapanır.
- **Kurulum düzeltmesi:** gerçek Linux llama.cpp arşivindeki ileri sıralı zincir sembolik bağlantılar güvenlik kontrolleri korunarak kurulabilir.
- **Mevcut modüller korunur:** Türkçe Wikipedia, 81 il haritası, yerel Türkçe-İngilizce çeviri ve Offline Eğitim Merkezi AI kurulmadan da kullanılabilir.

Linux: `sha256sum -c engelsiz-linux-x64.tar.gz.sha256`. Windows PowerShell: `Get-FileHash .\Engelsiz-Setup.exe -Algorithm SHA256`. Sonucu ilgili checksum dosyasıyla karşılaştırın. Sürüm varlıklarında platforma özel build provenance ve Windows installer QA raporu da bulunur; bunlar kaynak commit'i, sürümü ve artifact hash'ini bağlar.

AI için **Asistan → Motoru indir**, ardından istediğiniz modelde **İndir/Kur** seçin. Bilgi kaynaklarını ayrıca kurun. Mevcut kullanıcı verileri ve indirilen içerikler program güncellemesinde/kaldırılmasında korunur. Paket içindeki `runtime` ve `LICENSES` klasörlerini uygulamayla birlikte tutun.

## Gereksinimler ve bilinen sınırlar

- Ana uygulama/Kiwix/PMTiles Linux'ta statiktir. Hazır CPU AI motoru glibc 2.35+, çeviri motoru glibc 2.38+ gerektirir. Windows motorları Microsoft VC++ x64 runtime gerektirebilir.
- Lite/Balanced/Quality için 4/8/12-16 GB RAM başlangıç hedefidir, ölçülmüş uyumluluk garantisi değildir. Lite/Balanced Unsloth topluluk quantization, Quality resmi Qwen dağıtımıdır; modeller Apache-2.0, llama.cpp MIT lisanslıdır.
- Gerçek Linux motor kurulumu/çalıştırması doğrulandı ve kullanıcı Lite sohbeti doğruladı. Bu, kontrollü Türkçe kalite benchmark'ı, token/s veya tepe inference RAM ölçümü değildir.
- Native Windows CI installer QA çeviri kurulum/çalışma/kaldırmasını kapsar; gerçek Windows AI inference testi değildir. Temiz Windows 10/11 masaüstü, GPU ve fiziksel düşük RAM matrisi tamamlanmış gibi sunulmaz.
- Her soru bağımsız bağlamdır; sohbet ekrandan ayrılınca silinir. PDF metin çıkarımı, özel belge RAG, bulut AI, agent otomasyonu, ses ve görsel üretimi kapsam dışıdır. Sağlık/afet yanıtlarında asıl kaynağı okuyun.

Lite küçük boyutu nedeniyle eksik, hatalı veya kullanışsız yanıtlar verebilir. Kaynak bağlantıları model çıktısından bağımsızdır; doğruluğu asıl metinden kontrol edin. Daha güçlü donanımda Balanced veya Quality seçilebilir; hiçbir profil doğruluk garantisi vermez.
