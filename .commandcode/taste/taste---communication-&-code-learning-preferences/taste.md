# Taste - Communication & Code Learning Preferences
- Prefers interactive, permission-gated teaching: small steps with explicit STOP after each step, only continuing on `devam` / `sonraki` / `geçebiliriz` type confirmation. Confidence: 1.0
- Prefers learning-order over diff-order: first a concept map / lesson plan, then basics one-by-one, then big-picture, then file-by-file, then synthesis — never everything in one answer. Confidence: 0.95
- Prefers why-focused code explanations (architecture, data flow, decisions, business rules, edge cases, preserved behaviors) over repeating code or explaining every line. Confidence: 0.95
- Prefers beginner-safe explanations: define every term/syntax on first use, never assume Go/backend/systems knowledge, explicitly mark untaught syntax as black-box to be taught later. Confidence: 0.9
- Prefers tiny code blocks (only a few lines needed for the concept) always preceded by plain-language intent, not long dumps with line-by-line walkthroughs. Confidence: 0.9
- Prefers one concept or preferably one file per message with consistent structure (what it is / small isolated example / why needed in this project / relation to other files) plus simple flow diagrams for system flow. Confidence: 0.9
- Treats mid-lesson questions as part of the lesson: answer only the question in context, then pause and wait for `devam` without auto-advancing. Confidence: 0.95
- Prefers lessons in Turkish ending with synthesis (key takeaways) plus 3 short unanswered questions that test mental model, not memorization. Confidence: 0.9
