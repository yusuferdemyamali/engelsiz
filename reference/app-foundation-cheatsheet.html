App Foundation Cheatsheet

Lifecycle (app.go)

Resolve → Ensure → initLogger → database.Open → ListenLoopback(17321) → NewMux + web.Handler → Serve → waitForHealth(10s) → openBrowser → select shutdown

Portlar

Tercih 17321, fallback 127.0.0.1:0. Sadece loopback.

DB (db.go)

PRAGMA journal_mode=WAL, busy_timeout=5000, foreign_keys=ON → Migrate() → schema_migrations(version). Tx başına bir .sql dosyası.

Web (web.go)

ENGELSIZ_DEV_PROXY varsa reverse proxy. Yoksa embed dist/. /api/* → 404. Dosya yoksa → index.html (SPA fallback). Dosya yoksa → 503 "frontend not built".

Config (dirs.go)

Linux: ~/.config/engelsiz, ~/.local/share/engelsiz, ~/.cache/engelsiz. Windows: APPDATA/Engelsiz + LOCALAPPDATA/Engelsiz. ResolveFor(os, getenv, home) test edilebilir.

Komutlar

go test ./...
ENGELSIZ_DEV_PROXY=http://localhost:5173 go run ./cmd/engelsiz
scripts/build-frontend.sh  # frontend/dist üretir
