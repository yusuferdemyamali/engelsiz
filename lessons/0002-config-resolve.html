Config Resolve: ResolveFor XDG / Windows ayrımı

Mission: boot yollarını ezberden çizmek · Kaynak: internal/config/dirs.go:23-80, test: internal/config/dirs_test.go:14-92 · Önceki: 0001 App Lifecycle

Tek kazanım

Bu ders bitince ResolveFor(os, getenv, home) imzasını neden böyle olduğunu ve Linux vs Windows kök farkını tabloyla anlatacaksın. Hepsi cheatsheet'te özetli.

Kökler:
Linux: XDG_CONFIG_HOME → ~/.config · XDG_DATA_HOME → ~/.local/share · XDG_CACHE_HOME → ~/.cache
Windows: APPDATA → Roaming · LOCALAPPDATA → Local · CacheRoot = DataRoot
Alt: config/ · logs/ · downloads/ · content/ · runtime/ · cache/ · engelsiz.db

1. İmza neden 3 parametre?

func Resolve() (AppDirs, error) {
  return ResolveFor(runtime.GOOS, os.Getenv, homeDir())
}
// dirs.go:23-25

Resolve() gerçek dünyayı bağlar: OS + env + home. ResolveFor ise saf fonksiyon gibi davranır — test fakeEnv(map) verip "linux"/"windows" taklit eder (dirs_test.go:10-12). runtime.GOOS'u parametre yapmak, Windows dalını Linux'ta test etmeyi sağlar.

func fakeEnv(vars map[string]string) func(string) string {
  return func(k string) string { return vars[k] }
}

2. Linux dalı — XDG + fallback

configHome := getenv("XDG_CONFIG_HOME")
if configHome == "" {
  configHome = filepath.Join(home, ".config")
}
// aynı pattern: XDG_DATA_HOME → ~/.local/share
// XDG_CACHE_HOME → ~/.cache
// dirs.go:53-64

Boş string = tanımsız sayılır. Fallback hep home tabanlı, asla kaynak ağaca yazmaz — test bunu "cmd" içermez diye doğrular (dirs_test.go:32-36).

Kritik detay: LogDir = dataRoot/logs (dirs.go:72). Yani Linux'ta log, config'de değil datada. DBPath = dataRoot/engelsiz.db, CacheDir = cacheRoot/cache.

3. Windows dalı — Roaming vs Local

if osName == "windows" {
  appData := getenv("APPDATA") // boşsa ~/AppData/Roaming
  localAppData := getenv("LOCALAPPDATA") // boşsa ~/AppData/Local
  configRoot := filepath.Join(appData, "Engelsiz")
  dataRoot := filepath.Join(localAppData, "Engelsiz")
  // dirs.go:29-40

Roaming = makineden makineye gezen ayar. Local = büyük veri (DB, download). Bu yüzden ConfigRoot ≠ DataRoot burada da korunur, ama CacheRoot = DataRoot olur (dirs.go:42).

Kritik fark: LogDir = configRoot/logs (dirs.go:44) — Linux'tan farklı! Windows log'u Roaming altında. DBPath yine dataRoot altında (dirs_test.go:69-71 bunu assert eder).

4. Ensure() ne garanti eder?

func (d AppDirs) Ensure() error {
  for _, dir := range []string{d.ConfigDir, d.LogDir,
    d.DownloadDir, d.ContentDir, d.RuntimeDir, d.CacheDir} {
    os.MkdirAll(dir, 0o755)
    os.MkdirAll(filepath.Dir(d.DBPath), 0o755)
  }
}
// dirs.go:82-99, test dirs_test.go:74-92

app.Run içinde Resolve → Ensure ilk iki adım (app.go:45-50). Ensure idempotent: yoksa yarat, varsa dokunma. DB dosyasını yaratmaz, sadece klasörünü.

5. Birincil kaynak

Oku: XDG Base Directory Spec — 5 dk, XDG_CONFIG_HOME / XDG_DATA_HOME / XDG_CACHE_HOME tanımı. Go tarafı: os.UserHomeDir + filepath.Join.
