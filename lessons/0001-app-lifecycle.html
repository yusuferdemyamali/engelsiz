App Lifecycle: Run() baştan sona

Mission: bu branch'in nasıl boot ettiğini ezberden çizebilmek · Kaynak: internal/app/app.go:44-127

Tek kazanım

Bu ders bitince Run(ctx, opts) içindeki 7 adımı sırayla sayacaksın. Hepsi cheatsheet'te de var.

Akış: Resolve → Ensure → logger → Open DB → ListenLoopback(17321) → mux+web → waitForHealth → browser → signal bekle → shutdown

1. Kod

dirs := config.Resolve()      // XDG / APPDATA yolları
dirs.Ensure()                 // mkdir -p hepsi
logger := initLogger(dirs.LogPath)
db := database.Open(dirs.DBPath)  // WAL + migrate
ln, port := ListenLoopback(17321) // doluysa :0 fallback
mux := api.NewMux()           // /api/health
mux.Handle("/", web.Handler())// dist/ ya da dev proxy
waitForHealth(baseURL+"/api/health", 10s)
openBrowser(baseURL) unless --no-browser
select { ctx.Done / SIGINT / serverErr } → shutdown()

Neden health self-check? Server Serve(ln) goroutine'da başlıyor (app.go:81-86). Browser açmadan önce gerçekten cevap verdiğini kanıtlıyor. Başarısızsa logla + kapat + hata dön (app.go:89-93).

Neden loopback + fallback? 127.0.0.1:17321 tercih, doluysa 127.0.0.1:0 ile rastgele port (app.go:30-42). Dışarıya kapalı, tek kullanıcı.
