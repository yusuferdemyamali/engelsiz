# Engelsiz offline translation runtime: frozen worker dependencies.
#
# Installed with `pip install --require-hashes --no-deps -r requirements-runtime.txt`
# (or `uv pip install --require-hashes --no-deps`) into the PyInstaller build
# venv. Every wheel is pinned by hash for both supported build platforms.
#
# Deliberately excluded from argostranslate 1.11.0's upstream dependency set:
#   stanza==1.10.1, spacy, minisbd, sacremoses (+ their torch/CUDA/nvidia
#   closure, ~1GB). The worker (scripts/translation/worker/engelsiz_translate.py)
#   drives the real argostranslate Package/tokenizer/CTranslate2 path with an
#   explicit offline sentence splitter, so those sentence-boundary/model
#   backends are never imported (stubbed) and must not be frozen. sacremoses
#   is only needed for legacy BPE (.bpe.model) packages; the shipped tr/en
#   models use sentencepiece, and a BPE-only model fails closed with
#   model_invalid instead of pulling the extra stack.
#   minisbd is additionally a hard licensing exclusion: minisbd 0.9.5 on PyPI
#   is GNU AGPL-3.0 (verified 2026-11-04), which must not enter the frozen
#   distributable. The worker therefore keeps its dependency-free regex
#   OfflineSentencizer; no onnxruntime/minisbd/ONNX vendoring.
#
# ctranslate2 wheels on PyPI are CPU-only builds (oneDNN/mKL bundled, no CUDA
# runtime wheels). No nvidia/cuda packages may be added here.
#
# Interpreter: CPython 3.11.x on linux/amd64 and windows/amd64.
